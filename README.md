# Sync Vault — Media Dispatch & Sync Licensing Engine

Phase 1 prototype of the **Media Dispatch & Sync Vault** (`sync-vault`).
A browser-native 4-stem audition player + sync-licensing dispatch rail,
engineered by **Leoneigh Digital** for the **Leoneigh Unfiltered** catalog.

## Run locally

ES modules require an HTTP origin (not `file://`):

python3 -m http.server 8080
# or: npx serve .
